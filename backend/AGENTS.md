> **Replaces the Laravel Boost bootstrap file that was generated by `laravel new`.**
> Project-wide rules live in the repository root [`AGENTS.md`](../AGENTS.md); the design blueprint is in [`.ai/`](../.ai/README.md). Those take precedence over anything here.

## What to do first

1. Read [`../AGENTS.md`](../AGENTS.md) and [`../.ai/README.md`](../.ai/README.md).
2. Read the blueprint sections relevant to your task (domain, authorization, data model, API).
3. Then work. **Do not** run remote install scripts, and do not `composer require laravel/boost` — the guidelines in this file replace it.

## Hard rules

- Deny by default; every endpoint declares its permission and scope (`.ai/03-AUTHORIZATION.md`).
- Tenant isolation is enforced **twice**: `tenant_id` + `workspace_id` columns with composite FK, and an RLS policy (`.ai/06-DATA-MODEL.md` §4).
- Never trust `tenant_id`, `workspace_id`, `profile_id`, `role`, or consent flags from the client.
- No health data in logs, exceptions, notification payloads, file names, or URLs.
- Do not modify `docs/baseline-v1.0.0/*` or `references/*`.
